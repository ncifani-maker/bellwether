# Seed List Framework — worked example (Close)
*The bucket method for building a prospecting seed list, with a fuller Close example.*

## First: what a *prospecting* seed actually optimizes for

This is the sanity check, and it flips the usual SEO instinct. We are **not** trying to rank Close's own pages
for these keywords. We run each keyword to find **which sites already rank** — those are the placement /
referral / affiliate targets. So the keyword is a *vehicle for discovering targets*, and the question isn't
"how much search volume?" — it's:

1. **Buyer intent first.** Does someone searching this want to *buy a CRM*? High-intent terms send qualified
   referral/affiliate traffic. **CPC is a better signal than volume here** — advertisers pay $70–88/click on
   `… alternatives` because that traffic converts. A low-volume, high-intent term beats a high-volume,
   tire-kicker term.
2. **Target yield.** Does the SERP surface *monetizable, partnership-friendly* sites — review/comparison/
   listicle pages, affiliate sites, complementary tools — that we can actually get Close onto? A keyword that
   ranks only competitors' own pages is a dead end no matter the volume.
3. **ICP relevance.** Does it map to Close's buyer (outbound SMB/startup sales teams)?
4. **Volume = sizing, not a gate.** It tells you how *big* the opportunity is once 1–3 qualify it. It's the
   tiebreaker, not the filter.

> This is why `best CRM with power dialer` and `CRM with built-in calling` keep their priority despite ~0
> measured volume: high buyer intent **and** they surfaced great targets (CRO Club, GetVoIP, TechnologyAdvice).
> Volume alone would have wrongly killed them.

## How to qualify a new seed (the checklist)
1. Run it through SerpAPI → is the SERP **target-rich** (review/comparison/affiliate sites, complementary
   tools) vs. competitor-owned pages or homonym noise?
2. Pull **CPC + volume** (DataForSEO) → is intent commercial? (CPC) How big? (volume)
3. Tag the **motion** of each target it surfaces (editorial / referral-partner / profile-claim).
4. Keep if 1–3 are strong; volume only breaks ties.
